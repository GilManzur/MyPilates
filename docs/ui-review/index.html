MyPilates — סקירת מסכים

צילומי מסך אחרי השיפורים: לוח שנה חודשי, צבעי סטודיו, סטודיוים בהגדרות, סינון תשלומים ריקים, וליטוש UI/UX.

מה תוקן ושופר

  • הבר התחתון צומצם ל־4 טאבים; ניהול סטודיוים עבר להגדרות.
  • היומן מציג לוח חודשי עם שיעורים צבועים לפי סטודיו.
  • בטופס סטודיו אפשר לבחור צבע לזיהוי ביומן.
  • סטודיו בלי שעות בחודש לא מופיע במסך התשלומים / סיכום הבית.
  • תיקוני פריסה כדי שטקסט ארוך יישאר בתוך התיבות, ומרווחי ניווט נוחים יותר.
נוצר אוטומטית עם Playwright מתוך scripts/capture-ui-review.mjs. לפתיחה מקומית: פתחי את הקובץ ישירות או דרך שרת סטטי מתיקיית docs/ui-review.
